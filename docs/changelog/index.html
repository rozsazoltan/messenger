Follow the complete roadmap and its progress in Discussion #27.

The next stable release brings safer updates, native notification controls, and more polished desktop workflows while preserving the private, ad-free, distraction-free Messenger experience.

Already in progress

  • Insider updates, stable-channel recovery, and rollback foundations.
  • Multi-window support and a native downloads workflow.
  • Desktop notifications, badges, privacy controls, and mute-aware delivery.

Planned workflows

  • Multiple profiles and a focused set of conversation shortcuts.
  • Smaller installers, cleaner window lifecycle handling, and IME reliability.

Distribution

  • WinGet and Microsoft Store distribution are coming soon, alongside future Linux package repository integrations.
  • Automated package metadata updates for stable releases.

Insider builds

Testing the release path before stable.

v1.9.0-2

Insider August 10, 2026

Fixed

  • Restored the native media viewer layout for photos, videos, and other attachments in both direct and group conversations.
  • Kept media controls within the window below its title bar, without shifting the viewer content.
  • Kept the emoji picker and other compact Messenger popovers anchored to the conversation instead of inheriting the media-viewer offset.

v1.9.0-1

Insider August 5, 2026

Added

  • Configurable native message alerts, including a first-run choice between alerts, badge only, or not now.
  • Unread count or dot badges for the application and tray icons, plus controls for message-preview privacy and Messenger mute handling.
  • Refined Settings and downloads workflows for quicker control of notifications, window behavior, and recent files.

Changed

  • Notification delivery now uses native desktop integration rather than browser-style popups and stays off until you choose a mode.
  • The release pipeline now produces native Windows, macOS, and Linux artifacts: MSI, universal DMG, DEB, RPM, Arch, and AppImage.

Fixed

Improved unread-message detection so unrelated Facebook notification surfaces do not affect Messenger badges or desktop alerts.

v1.8.2-1

Insider July 2026

Added

  • Preview update channel controls for testing prerelease builds.
  • A recovery flow to roll back from an unsuitable update.
  • Release distribution improvements across supported desktop platforms.

Changed

Update checks now use fewer GitHub API requests and keep stable releases as the normal installation path.

v1.8.1

Insider April 22, 2026

Fixed

Fixed a Windows Enterprise edge case where preferences in the F3 panel could fail to save after an autostart removal error.

Looking forward to v1.9.0? Star the repository to follow the project. In the meantime, download the latest stable release. With update notifications enabled, Messenger Next will let you know when the next update is ready; press F2 to check manually at any time.

Stable history

Previous public releases

v1.8.0

Latest stable April 20, 2026

Added

  • The F3 preferences panel for window, tray, startup, and close behavior.
  • Optional multiple instances for advanced workflows.

Changed

Stabilized the desktop lifecycle, tray reconfiguration, focus recovery, and platform-specific restart behavior while keeping the installer smaller.

Fixed

Resolved duplicate tray icons on Windows and several cases where tray-related settings could leave the app inaccessible.

v1.7.0

Stable April 5, 2026

Added

  • Improved microphone and camera permission handling on macOS.
  • A Windows privacy-settings warning when microphone or camera access is blocked.
  • A Copy Image action in the context menu for Messenger images.

Fixed

Prevented a permission-check reload loop and restored page reload with F5 and Ctrl + R.

v1.6.0

Stable March 24, 2026
