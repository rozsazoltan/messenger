Messenger Next/macOS

Install Messenger Next on macOS.

The universal DMG works on Apple silicon and Intel Macs. Homebrew is a stable-only option once the first official cask is published.

Windows macOS Linux

Available now

Download the universal DMG

Open the DMG, drag messenger-next.app to Applications, then open it from Finder or Spotlight.

Download DMG

Homebrew

Install or upgrade with Homebrew

The official cask is published with the next stable macOS release. Homebrew publishes stable releases only.

Install

brew install --cask rozsazoltan/tap/messenger-next

Upgrade

brew upgrade --cask messenger-next

First launch

The app is not notarized by Apple yet. Review the release and use Finder Open if macOS requests confirmation.
