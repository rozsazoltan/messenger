Messenger Next/Windows

Install Messenger Next on Windows.

Choose the Windows package manager or download the direct MSI. Both install the stable release; neither depends on browser platform detection.

Windows macOS Linux

Package manager

Install with WinGet

Run this in Windows PowerShell or Terminal to install the current stable release.

Windows PowerShell

winget install --id Rozsazoltan.MessengerNext --exact

Direct installer

Download the MSI

Use the signed Windows installer when you prefer a direct download or need a local installer file.

Download MSI

Updates and availability

Use F2 in Messenger Next to check for updates. WinGet publishes stable releases. Microsoft Store distribution is planned and is not available yet.
